Problem
The Next route handlers and server modules duplicate backend lifecycle work, contradict ADR 0001, and still cannot complete jobs without the backend worker.
Solution
Reduce Next to a frontend adapter that calls or proxies to the Nest backend, then remove the native server modules once the adapter path is stable.
Benefits
  • locality: backend owns lifecycle
  • delete duplicate modules
  • one operational path
  • ADR and code align

Problem
Session bytes, global storage bytes, Redis keys, and DB reconciliation leak across modules, so quota correctness requires reading several implementations at once.
Solution
Concentrate admission, reservation, release, and reconciliation rules in one Reservation module that the Download lifecycle module uses.
Benefits

  • one fake Redis adapter
  • less key leakage
  • race tests get focused

Top recommendation

Deepen the backend Download lifecycle module

Tackle this first because ADR 0001 makes the backend the lifecycle owner; worker completion, cleanup, reservation reconciliation, and queued promotion should be tested through one deep module instead of several shallow state-transition calls.
